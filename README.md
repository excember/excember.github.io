# Adding "Get Your Hours Back" to your portfolio

Files mirror your repo layout:

- `index.html` — your landing page with the "Time Management Skills for IT Teams" placeholder replaced by the live course card (nothing else changed)
- `get-your-hours-back.html` — the full course, self-contained
- `offload-checklist.html` — the printable job aid (linked from the course's final screen)
- `assets/gyhb-thumb.png` — the card thumbnail

## Steps

1. Copy `get-your-hours-back.html` and `offload-checklist.html` to your repo root (next to `mahjong-course.html`).
2. Copy `assets/gyhb-thumb.png` into your `assets/` folder.
3. Replace your `index.html` with this one (or copy just the new card block from it).
4. Commit and push:

```
git add index.html get-your-hours-back.html offload-checklist.html assets/gyhb-thumb.png
git commit -m "Add Get Your Hours Back interactive course"
git push
```
